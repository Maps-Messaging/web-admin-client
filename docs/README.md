# Documentation Overview

Welcome to the technical documentation for the Web Admin Client. This repository contains several specialized guides focused on the core architecture and development workflows.

## 📚 Guides

### 🔐 [Authentication](./authentication.md)

Covers the `AuthService`, the `useAuth` hook, and how route guarding is implemented using TanStack Router.

### 🌐 [API Layer](./api.md)

Details our API-first workflow, including OpenAPI specification usage, type generation, and the integration of `openapi-fetch` with TanSK TanStack Query.

### 🛣️ [Routing & Navigation](./routing.md)

Explains the filesystem-based routing structure using TanStack Router and how protected routes are managed.

### 🧪 [Testing & Mocking](./testing.md)

A guide to running unit tests with Vitest and implementing network-level mocks using MSW (Mock Service Worker).

### 🎨 [UI & Styling](./styles.md)

Provides patterns for building UI components using Tailwind CSS, Radix UI, and CVA.
